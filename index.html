테스트 실행
k6 + irregular traffic

프로모션 페이지를 현실처럼 시험해보세요.

이 도구는 Hmall 기획전 페이지를 대상으로 불규칙한 초당 요청량(RPS)을 생성해, 실제 사용자처럼 들쭉날쭉한 트래픽 패턴을 시뮬레이션합니다. 서버의 응답 속도, 실패율, 비정상 트래픽 대응 여부를 사전에 검증할 수 있습니다.

지금 실행 기능 보기

테스트 요약

RPS 범위 10~50
구간 길이 20초
테스트 시간 5분
목표 지표 p95 < 3s

핵심 기능

실제 프로모션 이벤트 전 서버 상태를 점검할 수 있도록 설계된 부하 테스트입니다.

⚡

불규칙한 부하

초 단위로 RPS를 랜덤하게 바꿔서 정적이 아닌 현실적인 트래픽 패턴을 흉내 냅니다.

🧪

실제 사용자 유사도

모바일/데스크톱/브라우저별 User-Agent를 섞어 실제 프로모션 페이지 접근 환경에 가깝게 구성합니다.

📈

결과 지표 추적

응답시간, 실패율, p95/p99, 요청 수를 확인하며 성능 임계값을 기준으로 판단합니다.

동작 방식

k6의 ramping-arrival-rate를 사용해, 특정 시간 패턴 없이 무작위 추세를 형성합니다.

executor: 'ramping-arrival-rate'
startRate: RPS_MIN
timeUnit: '1s'
stages: buildIrregularStages()

실행 방법

로컬 환경에서 간단하게 시작할 수 있습니다.

1

k6를 설치합니다.

2

테스트 대상 URL을 실제 기획전 주소로 변경합니다.

3

스크립트 실행 명령을 입력합니다.

4

결과를 확인하고 서버 상태를 판단합니다.

k6 install
k6 run promo-page-load-test.js

# 결과 저장
k6 run --out json=result.json promo-page-load-test.js
